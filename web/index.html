Payday for open source.

Launch a coin for any public GitHub repo. Its creator fees fill that repo's glass vault, and only someone who can push to the repo can open it.

How it works

Merces is a launchpad on Robinhood Chain. You name a public GitHub repo and launch a coin for it on Pons. The coin's creator fee recipient is the repo's vault, a contract whose address is fixed by the repo's name, so it can receive fees before anyone has heard of Merces. The launcher's wallet is never in the path.

Every buy and sell adds the creator tax and the creator share of the Pons fee to that vault. A maintainer claims by committing one line, merces=0xTheirWallet, to a .merces file on the default branch. The Merces verifier reads it through the GitHub API, and one transaction opens the vault and pays out everything inside. After that, anyone can push new fees to the same wallet.

Why glass

Fees never pass through a Merces wallet. Each vault has no owner and can only pay the wallet its repo named. Anyone can read every vault on chain, every number on the site has a public endpoint, and Merces takes no cut.

$WAGE is the coin of Merces itself. It launches on Pons on 21 November 2026 at 15:00 UTC. Nothing on this site promises a return on any coin.
